# Crazy Hello World

Neon-glitch, high-conflict visual "Hello World" rebuilt from scratch.

## Run locally

```bash
python3 -m http.server 4173
```

Open: http://127.0.0.1:4173

## Controls
- PANIC ON/OFF: toggle primary chaos effects
- SHAKE ++: increase jitter intensity
- CALM MODE: reduce animation intensity for readability/accessibility
