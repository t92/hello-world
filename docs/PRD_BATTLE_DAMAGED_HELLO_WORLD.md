# PRD - 战损版 Hello World (from scratch)

## 1. 目标
重做一个“战损版 Hello World”单页作品，体现废土工业风：划痕、焦灼金属、断裂霓虹、颗粒噪点。

## 2. 视觉与品牌
- 主色：暗灰 `#1b1d1f`、锈红 `#8a2e24`、危险黄 `#f6c744`
- 辅助：霓虹断裂蓝 `#38d6ff`
- 纹理：噪点、锈斑、刮擦、烧灼边缘
- 字体：无衬线粗体（标题）+ 等宽字体（终端提示）

## 3. 功能范围
- 单页静态展示（无需后端）
- 中心主标题：`HELLO WORLD`，断裂霓虹发光效果
- 副标题：`SYSTEM DEGRADED // STILL ONLINE`
- 背景层：金属渐变 + 噪点 + 扫描线
- 装饰层：危险警示条、裂纹遮罩、随机火花动画
- CTA：`REBOOT SIGNAL` 按钮，悬停闪烁

## 4. 可访问性
- 对比度>=WCAG AA
- `prefers-reduced-motion` 时禁用火花与闪烁动画
- 键盘可聚焦按钮，焦点态清晰

## 5. 验收标准
1. 页面加载可见战损风主视觉，包含要求色板
2. 标题、背景、装饰与按钮效果均可见
3. 支持响应式：320px-1440px 区间布局不溢出
4. 通过 Lighthouse accessibility >= 90（目标）

## 6. 风险
- 纹理资源过多可能影响性能
- 过强动画可能影响可读性和眩晕用户
