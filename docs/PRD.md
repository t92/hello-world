# PRD — 癫狂版 Hello World (from scratch)

## 目标
重新开发一个“癫狂版 Hello World”单页，强调强烈视觉冲突与夸张动态，同时保持可读性与可用性。

## 用户故事
- 作为访问者，我能在 3 秒内感知“疯狂/失真/冲突”视觉风格。
- 作为访问者，我能清楚读到核心文案并找到主 CTA。
- 作为访问者，我在移动端和桌面端都能正常交互。

## 视觉与交互要求
1. 高冲突色彩（霓虹 + 深色底）
2. 夸张动态（抖动、闪烁、故障条纹）
3. 失真/撕裂/抖动视觉（glitch 特效）
4. 超常规排版与反差文案
5. 保证文字可读与 CTA 可点击

## 功能范围
- Hero 标题：Hello World（glitch）
- 副文案：反差语气文案
- CTA 按钮：可点击，具 hover/active 动效
- 疯狂卡片区：3 张抖动卡片
- 键盘触发：按 `G` 切换更强 glitch 模式

## 可访问性
- 保证前景/背景对比度可读
- 提供 `prefers-reduced-motion` 降级
- CTA 有可见 focus 样式

## 验收标准
- 页面可在本地打开并完整渲染
- 风格符合“癫狂版”且可读
- 交互（按钮、键盘切换）可用
- 代码以分支+PR 形式交付（若无远端权限则记录阻塞）
