# PRD: 喜庆版 Hello World（重开发）

## 1. 目标
从零开发一个“喜庆版 Hello World”单页，体现中国节庆氛围，支持桌面与移动端访问。

## 2. 视觉与内容要求
- 主色：红金配色（高对比）
- 元素：灯笼、烟花、飘带
- 文案：
  - 主标题：Hello World
  - 副标题：新春大吉，万事胜意！
  - 按钮：点亮祝福
- 动效：欢快但不过度，尊重 `prefers-reduced-motion`

## 3. 功能需求
1. 页面首屏展示节庆主视觉与祝福文案。
2. 点击“点亮祝福”按钮触发烟花粒子动画与祝福弹层。
3. 页面包含无障碍支持：
   - 语义化标签
   - 键盘可操作
   - 颜色对比满足可读性
4. 响应式布局：320px~1440px。

## 4. 验收标准
- 打开页面 2 秒内可见主标题与按钮。
- 动效不阻塞交互，60fps 优先。
- `Tab` 可聚焦主要控件；按钮可由 `Enter/Space` 触发。
- 在 `prefers-reduced-motion: reduce` 下关闭大幅动画。

## 5. 非功能约束
- 技术栈：原生 HTML/CSS/JS（轻量）
- 产物：
  - 设计链接（Figma Make）
  - 代码分支 + PR
  - QA 报告（Atlas）
  - 部署链接（AWS）

## 6. 风险
- Figma Make/Atlas 访问受账号与环境限制。
- AWS 发布权限可能受限。
