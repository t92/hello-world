# PRD — 喜庆版 Hello World（重开发）

- 日期：2026-03-07
- 仓库：https://github.com/t92/hello-world
- 版本目标：from scratch 重做，不复用历史实现

## 1. 背景与目标
构建一个“喜庆版 Hello World”单页应用，强调节日氛围（红金配色、烟花/灯笼装饰、祝福语动画），并保持可读性与可访问性。

## 2. 用户故事
- 作为访客，我打开页面即能看到醒目的 “Hello World” 喜庆主题展示。
- 作为访客，我可以点击按钮切换祝福语。
- 作为访客，我在手机和桌面端都能正常浏览。

## 3. 功能范围
### 必做
1. 首屏标题：Hello World
2. 喜庆视觉：红金渐变背景、节庆装饰元素（CSS）
3. 祝福语轮播或按钮切换（至少 3 条）
4. 基础动效（淡入/轻微漂浮）
5. 响应式布局（>=320px）

### 不做
- 后端服务
- 登录/数据持久化

## 4. 验收标准
1. 页面可在本地 `http://localhost:*` 访问；白屏率为 0。
2. 初次加载 2s 内显示主标题（本地环境）。
3. 交互按钮点击可切换祝福语，连续点击无报错。
4. Lighthouse 可访问性分数目标 >= 90（如可执行）。
5. 移动端（375x812）和桌面端（1440x900）布局不破版。

## 5. 风险
- 设计阶段依赖 Figma Make 在线可用性与账号权限。
- 若无法获取有效 Figma Make 证据，流程必须阻塞（按门禁）。
